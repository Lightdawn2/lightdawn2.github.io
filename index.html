Ventec APP

Plataforma comercial y operativa que conecta ventas, cartera de clientes y trabajo en terreno. Evolucionó desde un MVP en Flutter a un producto React Native / Expo con API propia, PostgreSQL y panel web.

Mi rolDesarrollo full stack y evolución de producto: levantamiento de requerimientos, arquitectura, aplicación móvil, API, datos, panel web, pruebas y preparación de entregas.

  • React Native
  • Expo
  • TypeScript
  • Fastify
  • Node.js
  • PostgreSQL
  • BigQuery
  • React
  • Docker
Explorar el proyecto

Responsabilidades y aportes

  • Construcción del dashboard comercial, ranking de productos, Cliente 360, agenda, contactos, visitas, cartera y simulador de reducción de costos.
  • Integración del ERP mediante BigQuery y sincronización controlada hacia PostgreSQL, con auditoría de cargas, deduplicación y alertas de antigüedad.
  • Diseño de permisos para vendedores, administradores y superadministración, conservando la historia cuando un usuario cambia de estado.
  • Integración de la flota Strix: asociación patente–vendedor, recorridos diarios y cruce de gestiones con ubicaciones registradas.
  • Implementación de geolocalización de visitas y cola de revisión, con decisiones humanas para aceptar o retirar registros.
  • Prototipado del módulo de prevención de riesgos: formularios oficiales, agenda, revisión, medidas correctivas, documentos PDF y futura operación sin señal.
  • Preparación de APK Android, despliegues de API y panel, migraciones, respaldos y documentación de cada entrega.

Resultados y decisiones

  • Detecté y corregí una comparación que mostraba crecimiento donde existía una caída; los períodos quedaron alineados al último mes cerrado y protegidos con pruebas de regresión.
  • Separé la lectura de BigQuery de la escritura productiva para que el servidor no almacenara credenciales de Google y cada carga quedara trazable.
  • Incorporé medición del estado de despliegue, alertas de datos atrasados y avisos de respaldo para que los fallos operativos dejaran de pasar inadvertidos.
  • La línea de prevención llegó a una maqueta navegable basada en cinco registros oficiales; su paso a producto se planificó en 21 bloques con seguridad y trabajo sin conexión desde el diseño.
  • Como exploración adicional, desarrollé una experiencia web con Phaser y controles táctiles alrededor del personaje Gotibel; permanece en evaluación local y no se presenta como publicada.

Evidencia del alcance

  • App móvil + API + panel web + base de datos
  • 43 migraciones registradas en la entrega verificada del 29-09
  • 112 comprobaciones de lógica y 39 de documentos en la maqueta de prevención

Evolución

MVP Flutter → migración a Expo → integración ERP y agenda → marcha blanca → auditoría de datos y flota → prevención de riesgos en evolución.

CKT APP / CONNEKT

Aplicación móvil de monitoreo de condición de aceite. Organiza plantas y equipos, combina telemetría reciente con históricos y presenta variables técnicas en una interfaz pensada para confiabilidad industrial.

Mi rolDesarrollo móvil e integración de telemetría: arquitectura de datos, proxy seguro, normalización de respuestas, experiencia de consulta y endurecimiento técnico.

  • React Native
  • Expo Router
  • TypeScript
  • TanStack Query
  • Zustand
  • Axios
  • Ubidots
  • API REST
Explorar el proyecto

Responsabilidades y aportes

  • Navegación por plantas y equipos, dashboard técnico por activo e histórico tabulado con selección de variable.
  • Visualización de actividad de agua, partículas de 4 / 6 / 14 µm, clasificación NAS y condición OD.
  • Proxy que combina históricos del servicio operacional con la cola reciente de Ubidots, manteniendo las credenciales fuera del cliente móvil.
  • Normalización, caché y reintentos con TanStack Query, junto con estados de carga, error, ausencia de datos y lecturas atrasadas.
  • Filtros temporales, paginación correcta y tratamiento explícito de la zona horaria de Chile.
  • Preparación de autenticación JWT, alcance por planta y equipo, CORS restringible y almacenamiento seguro de sesión.

Resultados y decisiones

  • La aplicación puede mostrar el histórico disponible y completar su extremo reciente con lecturas de Ubidots, reduciendo el desfase del proceso por lotes.
  • Corregí la consulta de series de 30 días cuando el límite del servicio devolvía sólo una fracción de los registros esperados.
  • El alcance JWT dejó de asumir acceso global: sin permisos explícitos, la sesión parte sin plantas ni equipos autorizados.
  • Los controles prioritarios incorporaron rol, etiqueta, estado accesible y objetivos táctiles de 48 dp.

Evidencia del alcance

  • 2 fuentes de datos combinadas: histórico operacional + Ubidots
  • 26 pruebas automatizadas con TypeScript, lint y formato en verde
  • Cliente Expo separado de credenciales y secretos del proxy

Evolución

Base móvil → integración de telemetría → auditoría de seguridad y accesibilidad → ajustes de históricos y zona horaria → lecturas recientes desde Ubidots.

Ecosistema web Belray

Reconstrucción de los sitios Bel-Ray y Ventec con arquitectura estática, contenido trazable y componentes reutilizables. Los desarrollos se reunieron en un monorepo preparado para mantener cuatro marcas con versionado independiente.

Mi rolArquitectura frontend, investigación y migración de contenido, diseño de componentes, rendimiento, accesibilidad y estrategia de mantenimiento.

  • Astro
  • TypeScript
  • Preact
  • React
  • pnpm
  • WooCommerce CSV
  • nginx
Explorar el proyecto

Responsabilidades y aportes

  • Bel-Ray: reconstrucción de páginas corporativas, servicios, sucursales, contacto y catálogo industrial.
  • Importación de 42 productos desde WooCommerce, conservando categorías, atributos, fotografías y enlaces a documentación técnica.
  • Ventec: reorganización de 46 páginas de origen en 26 rutas, con fichas de marcas, casos, servicios y productos de ingeniería.
  • Calculadora interactiva con islas Preact y salida HTML estática para reducir dependencias de ejecución en el servidor.
  • Monorepo pnpm con capa compartida y etiquetas de versión por sitio.
  • Connekt y RPurple incluidos en el alcance del repositorio, con sus nuevas implementaciones aún pendientes. El rediseño no se presenta como publicado en los dominios actuales.

Resultados y decisiones

  • Bel-Ray quedó reconstruido con sus rutas corporativas y un catálogo de 42 productos importados desde la fuente administrativa.
  • Ventec reorganizó 46 páginas de origen en 26 rutas sin perder la navegación: las páginas repetitivas pasaron a plantillas y las fichas con valor de búsqueda conservaron URL propia.
  • El JavaScript de la portada de Ventec bajó de 63,5 KB a 15,8 KB gzip al usar Preact/compat para la única isla interactiva.
  • Las fuentes de Ventec bajaron de 332 KB en 32 archivos a 124 KB en 6 archivos autoalojados, eliminando además conexiones a Google Fonts.
  • El catálogo y los medios conservan procedencia documentada; cuando faltó una fuente verificable se dejó el contenido pendiente en vez de inventarlo.

Evidencia del alcance

  • Bel-Ray: 14 rutas corporativas y 42 productos
  • Ventec: 46 páginas de origen reorganizadas en 26 rutas
  • Monorepo pnpm para Bel-Ray, Ventec, Connekt y RPurple

Evolución

Levantamiento de sitios existentes → reconstrucción Bel-Ray y Ventec → consolidación en monorepo el 8 de septiembre de 2026.
