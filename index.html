Ventec APP

Plataforma comercial para conectar ventas, cartera de clientes y trabajo en terreno. Evolucionó desde un MVP en Flutter a una aplicación React Native / Expo, con API propia, base PostgreSQL y panel de administración web.

  • React Native
  • Expo
  • TypeScript
  • Fastify
  • Node.js
  • PostgreSQL
  • BigQuery
  • React
  • Docker
Explorar el proyecto

Trabajo realizado

  • Dashboard de ventas con filtros, rankings y exportación; ingesta CSV con validación, deduplicación y registro de cargas.
  • Integración de ventas del ERP mediante BigQuery y sincronización hacia PostgreSQL, con controles de integridad y antigüedad de los datos.
  • Agenda comercial, contactos, visitas y seguimientos, con acceso por vendedor y perfiles administrativos.
  • Simulador de reducción de costos con fórmulas versionadas y administración de usuarios y parámetros.
  • Verificación de ubicación de visitas, revisión de actividad y reportes de problemas con seguimiento en Notion.
  • Integración de flota Strix, recorridos y cruce con gestiones comerciales implementados en desarrollo; despliegue pendiente según el registro del 9 de septiembre.
  • Preparación de APK Android, despliegue de API y panel, respaldo de datos y documentación para marcha blanca.

Evolución

MVP Flutter → migración a Expo → integración ERP y agenda → marcha blanca → gestión de flota en desarrollo.

CKT APP / CONNEKT

Aplicación móvil de monitoreo de condición de aceite en equipos industriales. Organiza plantas y equipos, consulta telemetría e históricos y presenta variables de condición en una interfaz pensada para confiabilidad.

  • React Native
  • Expo Router
  • TypeScript
  • TanStack Query
  • Zustand
  • Axios
  • Ubidots
  • API REST
Explorar el proyecto

Trabajo realizado

  • Navegación por plantas y equipos, dashboard por equipo e histórico tabulado con selección de variable.
  • Visualización de AW, partículas de 4 / 6 / 14 µm, clasificación NAS y condición OD.
  • Integración de históricos mediante un proxy backend y lecturas recientes desde Ubidots para complementar los datos disponibles.
  • Normalización de respuestas, caché y reintentos con TanStack Query; estados de carga, error, ausencia de datos y lecturas atrasadas.
  • Filtros temporales, paginación de históricos y tratamiento de la hora local de Chile.
  • Perfiles y permisos de demostración por planta y equipo. Autenticación productiva y validación técnica de umbrales aún pendientes.

Evolución

Base móvil → integración de telemetría → ajustes de históricos y zona horaria → complemento de lecturas recientes.
