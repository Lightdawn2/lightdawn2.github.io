# Portfolio — Franco Cortés

Portafolio personal desarrollado con HTML, CSS y JavaScript vanilla.

## Estructura del proyecto

```
portfolio-franco/
├── index.html          # Estructura principal (HTML semántico)
├── assets/
│   ├── css/
│   │   └── style.css   # Estilos y diseño
│   └── js/
│       └── main.js     # Interactividad y animaciones
└── README.md
```

## Características

- Diseño dark/terminal responsivo
- Cursor personalizado con animación fluida
- Terminal animada con efecto de tipeo
- Scroll reveal con IntersectionObserver
- Nav activo según sección visible
- 4 proyectos destacados con tecnologías
- Secciones: Hero, Proyectos, Skills, Experiencia, Educación, Certificaciones, Contacto

## Tecnologías

- HTML5 semántico
- CSS3 (variables, grid, flexbox, animaciones)
- JavaScript ES6+ (vanilla, sin frameworks)
